# Shree School Mart — Final Website Project

This is the final updated source code. The trophy and medal section now displays a total of **366 individual product images** in both the heading and the Browse Services sidebar.

## Quick start

1. Install Node.js 22 or newer.
2. Extract the ZIP.
3. Open Terminal/Command Prompt inside this folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the address shown in the terminal, normally `http://localhost:5173`.

For complete project explanation, file purposes, image counts and update instructions, read **`FINAL_PROJECT_GUIDE.md`**.
